## Mobile Framework — React Native \+ Expo

**What it is:** The open-source framework developed by Meta (Facebook) for building native mobile apps that run on both iOS and Android.

**Why it matters:** Your app feels and performs like apps built by billion-dollar engineering teams. Smooth animations, native gestures, and platform-appropriate design on both iPhone and Android, from a single shared codebase.

**Over-the-air updates:** New features and fixes are delivered instantly without requiring your users to update from the App Store. When Pixel Punch pushes an update, every user gets it automatically the next time they open the app. No waiting for Apple or Google review cycles for routine improvements.

## Backend & Real-Time : Firebase by Google

**What it is:** Google's mobile and web development platform, used by over 3 million apps worldwide.

**Cloud Firestore:** A real-time database that syncs data across all devices instantly. When a new order comes in, your user sees it appear in the app within seconds, no manual refresh needed.

**Cloud Functions:** Server-side logic that runs automatically on Google's global infrastructure, processing webhooks from your platform, sending push notifications, aggregating analytics data, and responding to events in real time.

**Firebase Cloud Messaging (FCM):** Google's push notification service, the same system that delivers notifications for Gmail, YouTube, and every Android app on the planet. Reliable, fast, and scales to any volume with no per-message limits.

<Tip>
  Apps powered by Firebase: **The New York Times, Duolingo, Alibaba, Lyft, Trivago, The Economist**
</Tip>

## Push Notifications : Expo Push \+ Apple APNs \+ Google FCM

**What it is:** A multi-layer notification architecture that reaches iOS and Android devices with 99.9% delivery reliability.

- **Apple Push Notification service (APNs):** Apple's official notification delivery system for all iPhones and iPads.
- **Firebase Cloud Messaging (FCM):** Google's notification delivery system for all Android devices.
- **Expo Push Service:** An intelligent routing layer that directs each notification to the right service (APNs for iOS, FCM for Android) automatically, with retry logic and delivery tracking built in.
- **Custom notification sounds per event type:** Different audio cues for orders, bookings, chat messages, and form submissions, so users know what happened without even looking at their phone.

## Live Chat : Real-Time Customer Communication

**What it is:** Integration with a dedicated live chat platform that connects website visitors directly with platform admins, with push notification delivery for every new message.

**Webhook-powered:** New messages trigger instant push notifications with no polling and no delays. When a visitor sends a message on a user's website, the relevant admin gets a push notification in seconds.

**Multi-widget support:** If you have chat widgets on multiple websites, all conversations from all sources appear in one unified inbox inside the app.

## Security & Infrastructure

**Google Cloud Platform:** The same infrastructure that runs Google Search, YouTube, and Gmail, with a 99.99% uptime SLA.

**HTTPS everywhere:** All data in transit is encrypted using TLS 1.3.

**Secure credential storage:** User credentials are stored using iOS Keychain (Apple's secure hardware enclave) and Android Keystore, the same mechanisms used to store Apple Pay and Google Pay data. Credentials never touch our servers.

**Your data stays yours:** Your app data lives in your own Firebase project. Pixel Punch manages the infrastructure and deployment, but you own the data. If you ever leave, you take it with you.
