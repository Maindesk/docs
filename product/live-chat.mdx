Live Chat connects your users to their website visitors in real time — with push notifications for every new message so conversations happen while leads are still engaged. No more visitors sending a message and waiting hours for a response. No more missed opportunities because a user wasn't at their computer.

## Key Capabilities

- **Conversation list** — all active and historical chat conversations in one place, with the most recent message and timestamp
- **Status filters** — filter conversations by status:
  - **Open** — new or ongoing conversations that need attention
  - **Awaiting** — the user has replied and is waiting for the visitor to respond
  - **Closed** — resolved conversations archived for reference
- **Real-time messaging** — messages update every 3 seconds within an open conversation, so responses feel live
- **Push notifications per message** — every new message from a visitor triggers a push notification, with the visitor's name and message preview in the notification
- **Unread badge count** — the navigation shows how many unread conversations there are at all times
- **Widget identification** — each conversation shows which chat widget (and therefore which website) the visitor came from — critical for users who manage multiple sites

## How It Works

1. A visitor types a message in the chat widget on the user's website.
2. A push notification arrives on the user's phone: "💬 [Visitor Name] — via [Widget Name]"
3. The user taps the notification and lands directly in that conversation.
4. They type a reply — the visitor sees it within seconds on the website.
5. The conversation continues in real time from the phone.
6. When resolved, the user closes the conversation to move it to the Closed tab.

## Why It Matters

Live chat is one of the highest-converting touchpoints on any website — but only if someone is there to respond. Your App removes the constraint of needing to be at a computer. Users can have real conversations with potential customers from anywhere — on the way to a meeting, between appointments, or from the couch at 9pm when a motivated buyer reaches out.
