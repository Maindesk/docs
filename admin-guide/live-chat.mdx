title: "Live Chat"

The Live Chat section in the admin view shows all incoming conversations from visitors on your users' websites. Every new message triggers a push notification, so you can respond while the visitor is still engaged, regardless of where you are.

## Conversation Statuses

Conversations are organized into three status tabs:

| Status | Meaning | What to Do |
| --- | --- | --- |
| **Open** | A visitor sent a message that has not yet been fully resolved | Respond as soon as possible, this is a live, active conversation |
| **Awaiting** | You've replied and are waiting for the visitor to respond | No immediate action needed, monitor for a reply |
| **Closed** | The conversation has been resolved and archived | Review if needed; no further action required |

The **Open** tab is your priority queue. When you first open Live Chat, check the Open tab for any conversations that need a response.

## Responding to a Conversation

<Steps>
  <Step title="Open Live Chat">
    Navigate to **Live Chat** from the admin section of the side menu.
  </Step>
  <Step title="Check the Open tab">
    Tap **Open** to see conversations that need your attention. These are visitors who are potentially still on the website waiting for a reply.
  </Step>
  <Step title="Open a conversation">
    Tap any conversation card to open the message thread.
  </Step>
  <Step title="Read the conversation history">
    Review any previous messages to understand the context before replying.
  </Step>
  <Step title="Type and send a reply">
    Type your response in the message field at the bottom and tap Send.
  </Step>
  <Step title="Wait for or close the conversation">
    If the visitor responds, the conversation returns to **Open**. Once resolved, mark it as **Closed** using the close button.
  </Step>
</Steps>

## Real-Time Polling

The conversation view refreshes every 3 seconds while you're inside an open conversation. New messages from the visitor appear automatically, no manual refresh needed.

## Push Notifications

Every new message from a visitor triggers a push notification with:

- The visitor's name (or "Visitor" if they haven't provided one)
- The widget name (which website the message came from)
- A preview of the message

Tapping the notification opens the app directly in that conversation.

## Unread Badge Count

The Live Chat icon in the navigation shows a badge count for the number of unread conversations. This stays visible as you navigate around the app, so you always know if someone is waiting.

## Widget Identification

Each conversation card shows which chat widget and website the message came from. If you manage multiple users' websites or run a single platform with multiple live chat widgets, this tells you which context the conversation belongs to, before you open it.

<Tip>
  Response time is the single biggest factor in live chat conversion. Visitors who receive a reply within 60 seconds are dramatically more likely to become customers than those who wait even 5 minutes. Push notifications make a 60-second response achievable from anywhere.
</Tip>

<Note>
  Live Chat requires a connected LiveChat workspace. If your platform does not have a LiveChat integration configured, the Live Chat section will display a setup page with instructions. Once connected, the app detects the integration automatically.
</Note>
