The Projects Management section shows every project (website) created by every user on your platform, with status filtering so you can quickly find Active, Trial, or Expired projects and take action.

## The Projects List

Each project appears as a card showing:

- **Project name** : the website or funnel name
- **Owner** : the user who created the project
- **Status badge** : current project status (Active, Trial, Expired)
- **Creation date**
- **Domain** : the website's URL (if a custom domain is connected)

## Project Statuses

| Status | Meaning |
| --- | --- |
| **Active** | Project is on a paid plan and fully operational |
| **Trial** | Project is in a trial period, limited time before action is required |
| **Expired** | Trial ended or plan lapsed, project may have limited functionality |

## Filtering Projects

Filter the projects list by status to find exactly what you're looking for:

- **Active** : all paid, live projects
- **Trial** : all projects currently in trial
- **Expired** : projects that need intervention (conversion push or cleanup)

## Project Detail Page

Tap any project card to open its full detail view:

- Project name and URL
- Owner contact information
- Current plan (or trial status)
- Trial start and end dates (if applicable)
- Project creation date
- Activation history (all plans this project has been on)

From the detail page, you can also access the **Activate** button to move a project to a paid plan directly. See [Project Activation](/admin-guide/project-activation) for step-by-step instructions.
